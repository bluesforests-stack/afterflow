# 遗流 AFTERFLOW

一件以分组放射线簇和字符尘埃呈现数字痕迹的生成式交互艺术作品。

## 本地观看
直接用现代浏览器打开 `index.html`。所有样式与脚本均已内嵌，无构建步骤，无外部依赖，无网络请求。

- 悬停 / 拖动：扰动字符尘埃
- 点击 / 轻触：触发放射爆散
- 滚动：卷动信息流
- 密度滑杆：调整字符数量
- 空格：暂停 / 继续
- H：进入 / 退出沉浸模式；Esc：退出沉浸
- 留存：将当前字符场保存为 PNG
- 系统开启减少动态效果时，初始画面自动暂停，可手动继续

## 发布到 GitHub Pages
1. 在 GitHub 新建一个公开仓库，例如 `afterflow`。
2. 将本文件夹内的 `index.html`、`.nojekyll`、`README.md` 上传到仓库根目录，提交到 `main` 分支。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`，点击 Save。
5. 等待部署完成后，分享 Pages 页面显示的网址。通常形式为 `https://你的用户名.github.io/afterflow/`。

不要将整个压缩包作为一个文件上传；请先解压后上传其中的文件。本作品适合桌面及移动端浏览器，桌面大屏效果最佳。

## 生成机制
15 个随机簇中心各自生成 11 条角度相近的射线。字符按射线方向生成，带有速度、曲率和有限寿命；透明度随寿命渐隐。鼠标附近的排斥力、点击的放射粒子及滚轮的竖向流场共同改变画面。轨迹数代表当前会话中的交互触发次数，不是实际网络数据。

画面中的符号是随机生成的艺术材料，所有交互仅在本地计算，不采集或上传观众数据。重置和窗口尺寸变化会重新生成随机场。留存图像只包含字符场及作品落款，不包含网页操作界面。
